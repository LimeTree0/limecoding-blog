# 기능과 개발 범위

## 상태 안내

아래 확정된 진행 범위와 기존 초기 범위 제안을 구분한다. 초기 범위 제안 전체가 출시 요건으로 승인된 것은 아니다.

## 확정된 진행 범위 — 2026-11-08

1. 샘플 MDX 글 2개와 메타데이터를 읽어 목록에서 상세 본문까지 이동하는 최소 흐름을 만든다.
2. 이 흐름 위에 기존 Figma 시안의 공통 글꼴·색상·여백, 헤더와 홈 화면을 적용한다.
3. 글 상세의 본문 너비·글꼴·여백·코드 스타일을 적용한다.
4. 검색과 그래프는 디자인 적용 이후에 검토한다. 콘텐츠 기능 전체를 먼저 완성하지 않는다.

현재 구현은 실제 MDX 기반 홈·전체 글 목록·상세 페이지, 태그 필터, 반응형 목차와 코드 복사를 포함한다. 검색·연결 탐색은 준비 중인 비활성 상태로 표시한다. 시안의 예시 글과 숫자는 실제 글 데이터로 대체한다.

## 초기 범위 제안

| 영역 | 기능 | 검토 사항 |
| --- | --- | --- |
| 홈 | 블로그 소개와 글로 진입하는 화면 | 구체적인 구성은 기존 목업 확인 |
| 글 목록 | 공개된 글 목록과 상세 진입 | 정렬, 페이지네이션 등은 미정 |
| 글 상세 | 제목과 본문을 읽는 화면 | 코드 블록, 이미지 등 콘텐츠 표현 확인 |
| 검색 | 원하는 글 탐색 | 검색 UI 수정 가능, 검색 방식 미정 |
| 글 간 이동 | 관련 글이나 내부 링크로 이동 | 관계를 직접 작성할지 자동 추출할지 미정 |

홈과 글 상세 화면은 이전에 데모를 요청했던 주요 화면이다. 그 외 화면과 세부 동작은 기존 자료와 함께 재확인한다.

## 콘텐츠 관리

- 현재 구현: `src/content/posts/`의 MDX와 `src/content.config.ts`의 posts 컬렉션을 사용한다.
- 메타데이터: `title`, `description`, `publishedAt`, 선택적 `updatedAt`, `tags`, `draft`를 읽는다. 초안은 공개 목록과 상세 경로에서 제외한다.
- 글 주소: 컬렉션 ID를 `/posts/{id}/`에 연결한다.
- 미결정: 본문 이미지 관리 규칙, 카테고리 도입 여부
- 글 사이의 링크 및 관계 표현 방식

현재는 파일 기반으로 운영한다. DB와 CMS 도입은 필요성을 확인한 뒤 결정한다.

## 향후 확장 구상

### 문서 그래프

글 사이의 관계를 시각화하고 연결된 글로 이동하는 기능을 고려한다.

구현 전에 관계의 의미, 전체 그래프와 현재 글 주변 그래프 중 어떤 경험을 제공할지, 모바일에서의 사용 방식을 정해야 한다. 특정 그래프 라이브러리는 선택하지 않았다.

### AI 탐색

블로그에 축적한 내용을 소개하거나 관련 글을 안내하는 기능을 고려한다.

구현 전에 사용 사례, 답변 근거 표시, 호출 비용과 운영 방식, 서버 필요 여부를 정해야 한다. 특정 모델·RAG 구성·API 제공자는 선택하지 않았다.

## 초기 범위로 합의되지 않은 항목

회원가입, 로그인, 댓글, 웹 관리자, CMS, 외부 DB, AI 채팅, 그래프 편집기는 초기 범위로 합의되지 않았다. 필요해지면 별도로 검토한다.

## 권장 진행 순서

1. 기존 목업과 디자인 자료를 확인한다.
2. 초기 화면·기능·콘텐츠 형식·기술 스택을 정한다.
3. 글을 게시하고 읽을 수 있는 기본 블로그를 만든다.
4. 검색과 글 간 탐색을 개선한다.
5. 실제 글이 축적된 뒤 그래프와 AI 기능의 필요성을 검토한다.

위 순서는 초기 개발 제안이다. 현재 작업 순서는 상단의 확정된 진행 범위를 우선한다.
