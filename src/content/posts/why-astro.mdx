## 어떤 블로그를 만들고 싶은가

개발하면서 배운 내용과 고민한 과정을 기록하려고 한다.
답을 정리하는 것뿐 아니라, 당시 어떤 이유로 선택했는지도 남기고 싶다.

글 하나를 읽고 끝나는 블로그보다는 관련 글을 타고 이동하며
지식을 연결해서 탐색할 수 있는 공간을 만들고 싶다.

## Astro를 선택한 이유

처음에는 익숙한 React를 중심으로 만드는 방법을 생각했다.
Next.js도 사용해봤지만, 이번에는 기존에 느꼈던 복잡성과 불편함을
줄일 수 있는 구성을 시도해보고 싶었다.

Astro는 처음 사용한다.
글과 기본 페이지는 정적으로 생성하고,
사용자 조작이 필요한 부분에는 React를 넣는 방식을 경험해보기로 했다.

> 이번 프로젝트에서는 새로운 도구를 배우는 것과
> 실제로 글을 게시할 수 있는 블로그를 완성하는 것을 함께 목표로 한다.

## 초기 기술 구성

| 역할 | 선택 |
| --- | --- |
| 페이지와 레이아웃 | Astro |
| 인터랙티브 UI | React |
| 글 작성 | MDX |
| 배포 플랫폼 | Cloudflare |

초기에는 저장소 안의 MDX 파일로 글을 관리한다.
별도 DB나 관리자 화면은 필요해질 때 검토하려고 한다.

## 앞으로 만들고 싶은 기능

- 관련 글로 이동할 수 있는 내부 링크
- 글 사이의 연결을 보여주는 문서 그래프
- 축적한 글을 소개하거나 탐색을 돕는 AI 기능

우선은 글 목록과 상세 페이지부터 만든다.
그래프와 AI 기능은 기본 블로그가 동작한 뒤 확장할 예정이다.
